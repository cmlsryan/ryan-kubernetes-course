# Kubernetes 基礎架構

從連鎖公司的管理問題開始，
一步一步理解 Kubernetes 的基礎架構。

這堂課最後會理解：

- Cluster
- Node
- Pod
- Container
- Scheduler

---

## 本堂課先用一個生活化比喻

想像你經營的是一間大型連鎖公司。

公司裡有：

- 一個「總部」
- 很多間「分店」
- 不斷出現、需要被安排的「工作單位」

先不要急著把它們對應成 Kubernetes 的專有名詞。

我們會先從生活情境開始思考，
之後再一步一步揭曉正式名稱。
