# 今天唯一目標：看懂 Kubernetes 如何管理與安排工作

今天不追求學很多指令。

我們只要真正弄懂 **5 件事**：

## 01｜為什麼需要 Kubernetes

它到底想解決什麼問題？

## 02｜Cluster 是什麼

整個 Kubernetes 系統的範圍包含哪些東西？

## 03｜Node 是什麼

到底是誰在提供 CPU、記憶體與運算資源？

## 04｜Pod 與 Container 的關係

Kubernetes 安排的是誰？

真正執行程式的又是誰？

## 05｜Scheduler 負責什麼

當新的工作出現時，

到底是誰決定它應該去哪一台機器？

---

## 今天的學習方式

我們不會一開始就背定義。

而是按照這個順序：

**情境 → 提問 → 推理 → 揭曉概念 → 實際操作 → 觀察結果**

先知道 Kubernetes 想解決什麼問題，

再記住這些東西叫什麼名字。
